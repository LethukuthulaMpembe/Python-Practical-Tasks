# 📚 Course Outline

This repository follows the **Python Programming** course offered by **FNB App Academy**.

---

# Python Fundamentals

## Unit 1: Introduction to Python

### What you'll learn:

* Explain what Python is and describe three real-world applications of the language.
* Set up a working Python development environment on your own device.
* Write and run a basic Python script using `print()` and `input()`.
* Declare variables using the correct data types: `str`, `int`, `float`, and `bool`.
* Use `type()` to inspect the data type of any value.

---

## Unit 2: Manipulating Strings

### What you'll learn:

* Apply at least seven string methods including `upper()`, `lower()`, `title()`, `strip()`, `replace()`, `find()`, and `split()`.
* Use `len()` to count characters in a string.
* Access individual characters and substrings using indexing and slicing.
* Format output strings cleanly using f-strings.
* Concatenate strings using `+` and format them with f-strings.

---

## Unit 3: Manipulating Numbers

### What you'll learn:

* Perform arithmetic using Python's seven operators:

  * `+`
  * `-`
  * `*`
  * `/`
  * `//`
  * `%`
  * `**`
* Explain the difference between integer division (`//`) and regular division (`/`).
* Convert between data types using `int()`, `float()`, and `str()`.
* Apply `round()` and `abs()` to numeric values.
* Build a multi-function calculator using arithmetic and type casting.

---

# Program Logic and Data Structures

## Unit 4: Storage and Access

### What you'll learn:

* Create and manipulate lists using indexing, `append()`, `remove()`, `insert()`, and slicing.
* Create and use dictionaries with key-value pairs using `.get()`, `.keys()`, `.values()`, and `.items()`.
* Explain the difference between mutable and immutable data types.
* Build a list of dictionaries to represent structured collections of real-world data.
* Iterate over lists and dictionaries using `for` loops.

---

## Unit 5: Selection of Tasks

### What you'll learn:

* Write `if`, `elif`, and `else` statements to control program flow based on conditions.
* Use comparison operators (`==`, `!=`, `<`, `>`, `<=`, `>=`) correctly in conditions.
* Combine conditions using logical operators: `and`, `or`, and `not`.
* Use the `in` keyword to check membership in a list or string.
* Nest conditional statements where appropriate and explain when to use `elif` versus separate `if` statements.

---

## Unit 6: Repeating Tasks

### What you'll learn:

* Write `for` loops to iterate over lists, dictionaries, strings, and `range()`.
* Write `while` loops to repeat code until a condition becomes `False`.
* Use `range()` with start, stop, and step arguments.
* Use `break` to exit a loop early and `continue` to skip the current iteration.
* Combine loops with conditionals to solve multi-step real-world problems.
